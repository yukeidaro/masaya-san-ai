# カレンダー自動登録スキル

タスクを「やることリスト」ではなく **カレンダーの時間の枠** に置く。人は15分前の通知を見て着手するだけにする。

## 前提

- Google カレンダーにつながっていること（Claude のコネクタ、または MCP）
- 空き枠の判断には、**仕事用・個人用など、予定が入るすべてのカレンダー** を読めること。読めないカレンダーがあれば最初に伝える

## いつ発動するか

- 会話の中で、**人が手を動かす必要があるタスク** が確定したとき
  - 例：相手に送る文面を確認する、判断する、電話する、現物を見る
- エージェントだけで終わるタスク（調べる、下書きを作るなど）は入れない。それはその場で進める
- 内容・期日があいまいなタスクは入れず、「要確認」として本人に聞く

## 手順

1. **タスクを1行にする**：動詞で終わる具体的なタイトルにする（例：「A社への見積もり返信を確認して送る」）。
2. **見積もる**：所要時間を 15分・30分・45分・60分・90分 のどれかで見積もる。90分を超えるものは分けて、それぞれを入れる。
3. **期限を決める**：会話に期限があればそれに従う。なければ「重要度×急ぎ度」で、今日・明日・今週中のどれかにする。
4. **空き枠を探す**：期限までの予定をすべてのカレンダーから読み、次のルールで枠を選ぶ。
   - 勤務時間内（既定は 9:00〜19:00。本人の設定があればそれに従う）
   - ミーティングの直前直後 10分はあける
   - 1日に入れるタスクの合計は、空き時間の半分まで（突発対応の余白を残す）
   - 期限までに枠がなければ、入れずに「枠が足りない」と本人に伝え、何を動かすか聞く
5. **登録する**：次の形で予定を作る。
   - タイトル：`[Task] <タスク名>`
   - 説明：何のためか（1行）、完了の目安、元になった会話やファイルのリンク
   - 通知：**15分前**
   - 予定の公開範囲：自分だけ（他の人を招待しない）
6. **報告する**：入れた予定を「日時｜所要時間｜タイトル」の一覧で返す。

## やってはいけないこと

- 既存の予定を動かす・消す（必要なら提案だけする）
- 他の人を招待する、相手のカレンダーに入れる
- 同じタスクを二重に入れる（入れる前に同名の予定がないか確認する）

## 調整のしどころ（自分向けにチューニングする）

- 勤務時間、1日に入れる上限、タスクを入れたくない曜日・時間帯
- 予定の色分け（例：タスクは緑、ミーティングは黒）
- Grok ボットなど別の入り口から来たタスクも、このルールで空き枠に入れる
