# NotebookLM ポッドキャスト化

作るのは PC（Claude Code が自動で）、聞くのはスマホ（NotebookLM アプリ）。
元の資料は書き換えず、「耳で聞いて分かる形」に組み直した新しい資料を作って NotebookLM に入れる。

## 最初の準備（1回だけ・人がやる）

1. スマホに **NotebookLM アプリ**（iOS / Android）を入れ、PC と同じ Google アカウントでログインする。
2. PC の Chrome で https://notebooklm.google.com を開き、同じ Google アカウントでログインしておく。
3. Chrome に **Claude in Chrome**（Claude が Chrome を操作するための拡張機能）を入れ、Claude Code から使えるようにしておく。
4. 毎晩自動で作る場合は、Claude デスクトップアプリの定期タスクに次の内容を登録する（例: 毎日 21:00）。
   > 今日の Claude Code の作業をポッドキャスト化して（Skill notebooklm-podcast）

## 2つの使い方

- **A. 今日の作業モード**: 「今日の作業をポッドキャスト化して」。その日の Claude Code の作業を集めて音声にする。
- **B. 資料モード**: 「この資料をポッドキャスト化して」とファイルや本文を渡されたとき。渡された資料を音声にする。

## 手順

### 1. 材料を集める

**A. 今日の作業モード**
- `~/.claude/projects/` の中から、今日更新された会話の記録（`.jsonl`）を探す。
- それぞれの記録から、人が頼んだこと・Claude の最後の返答・決まったこと・作ったファイルだけを拾う。ツールの出力やコードの中身はほぼ捨てる。
- 記録に出てくる作業フォルダが git リポジトリなら、`git log --since=midnight --oneline` で今日の変更も足す。
- 作業がほとんど無い日（会話が 1 件だけで短いなど）は、音声は作らずに「今日は材料が少ないので作りませんでした」と報告して終える。

**B. 資料モード**
- 渡された資料を全部読み、何の資料か・誰が聞くのかをつかむ。元のファイルは書き換えない。

### 2. 外に出してはいけないものを消す

NotebookLM（Google）に送る前に、次のものを必ず消すか伏せる。
- パスワード、API キー、トークン、カード番号などの秘密情報
- 他人のメールアドレス・電話番号・住所
- お客様の名前や社外秘の数字のうち、聞かせなくても話が通じるもの（「A 社」のように置き換える）

迷ったものは消す。消したものの数だけ、最後の報告に書く。

### 3. 「聞く用」に組み直す

`~/NotebookLM-podcast/` に新しい Markdown を作る。ファイル名は
A なら `YYYY-MM-DD-作業ポッドキャスト.md`、B なら `<元の名前>-podcast.md`。
見出しは次の 8 つに固定する。

1. **この資料の目的**: 何のための話か（2〜3文）
2. **重要な結論3つ**: 先に結論を言う
3. **前提知識**: 聞く前に知っておくと分かりやすいこと
4. **重要な専門用語**: 1つ1行で、「平たく言うと〜」の形でやさしく
5. **本編の論点**: 中身。A なら「今日やったこと」を作業ごとに、何のために・何をして・どうなったか
6. **意思決定ポイント**: 決めたこと、迷っていること、どう判断したか
7. **次にやるべきこと**: 明日以降のアクション
8. **会話向きの本文**: 読み上げられることを前提にした、話し言葉の原稿（800〜1500字）

書き方のルール:
- 1文を短く。表・コード・URL の羅列は入れない（耳では分からない）
- 細かい背景や出典の羅列は削り、判断や次の行動に関わることを残す
- 数字は大事なものだけにする

### 4. NotebookLM に入れて音声を作る

Claude in Chrome で次を行う。画面の文言やボタンの位置は変わることがあるので、決め打ちせず、画面を読んで同じ意味のボタンを探す。

1. https://notebooklm.google.com を開く。ログイン画面が出たら操作を止め、本人にログインを頼む（パスワードは入力しない）。
2. 新しいノートブックを作る。名前は A なら「作業ポッドキャスト YYYY-MM-DD」、B なら資料の題名。
3. ソースの追加で「テキストを貼り付け（コピーしたテキスト）」を選び、手順 3 で作った Markdown の全文を貼って登録する。
4. 音声の言語が日本語になっているか確かめる（設定の「出力言語」など）。日本語でなければ日本語にする。
5. Studio などにある **Audio Overview（音声解説）** を開き、形式は対談（Deep Dive）にする。カスタマイズ欄に次の指示を入れて生成する。

```text
移動中に聞いて理解できるよう、専門用語は平易に噛み砕いてください。
細かい背景は省き、判断や次の行動に直結することを優先してください。
特に「重要な結論3つ」と「次にやるべきこと」を軸に、具体的に語ってください。
```

6. 生成が始まったことを確かめたら終わってよい。生成は Google 側で続くので、ブラウザを閉じても止まらない。

### 5. 報告する

次の形で短く報告する。
- ノートブックの名前と URL
- 組み直した Markdown の場所
- 伏せた情報の件数（中身は書かない）
- 聞き方: 「スマホの NotebookLM アプリ → ノートブックを開く → 音声を再生（ダウンロードしておけばオフラインでも聞けます）」

## うまくいかないとき

- **Claude in Chrome が使えない・画面が変わって操作できない**: 手順 4 は飛ばし、組み直した Markdown を Google ドライブに保存して終える。報告で「NotebookLM で新しいノートブックを作り、ソースの追加で Google ドライブからこのファイルを選び、Audio Overview の生成ボタンを押してください」と人に頼む。
- **ノートブックの数や生成回数の上限に当たった**: 無理に古いノートブックを消さない。上限に当たったことを報告して止まる。
- **音声が英語になった**: 出力言語の設定を日本語にして作り直す。

## やってはいけないこと

- 元の資料を書き換える・消す
- 秘密情報や他人の個人情報を NotebookLM に送る
- パスワードを入力する、ログインを代わりに行う
- 既存のノートブックやソースを消す
- 作ったノートブックを誰かに共有する（共有は本人が決める）
