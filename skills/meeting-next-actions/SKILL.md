# ネクストアクション自動化スキル

ミーティングで「あとで送ります」「調べておきます」と口に出したことを、忘れる前にタスクにして動かす。
**送信・公開・確定など取り消しにくい操作は、必ず人の承認を挟む。**

## 前提

- 文字起こしが読めること（Wispr Flow、Notion の AI ミーティングノート、Zoom の録音など、何でもよい）
- 下書きの置き場所（Gmail の下書き、Notion、ローカルのフォルダなど）が決まっていること

## 手順

1. **拾う**：文字起こしから、誰かが「やる」と言ったことをすべて拾う。
   - 「〜します」「〜送ります」「〜しておきます」「次回までに〜」など
   - 自分（このスキルの持ち主）が言ったものと、相手が言ったものを分ける。相手の分は記録だけして実行しない
   - 話者が分からないものは、文脈から推定し、推定と書く
2. **分ける**：自分の分を次の3つに分ける。

   | 区分 | 判断基準 | 扱い |
   | --- | --- | --- |
   | 人不要 | 調べる、ファイルを探す、資料をまとめる、下書きを作るなど、間違えてもやり直せる作業 | その場で実行し、**下書きの段階まで** 進める |
   | 人必要 | 人に送る、予定を確定する、公開する、お金や契約に関わる、消す | 下書きや準備までは進め、**実行は人の承認を待つ** |
   | 要確認 | 誰がやるか・期日・中身があいまい、聞き取りが怪しい | 何も実行せず、確認したいことを1行で残す |

3. **進める**：人不要のものを実行する。人必要のものは、送る直前の状態（下書き、送付先、添付）まで準備する。
4. **時間を取る**：人必要のもので作業時間が要るものは、`calendar-task-scheduler` スキルでカレンダーの空き枠に入れる。
5. **報告する**：次の形で返す。

   ```
   ## ネクストアクション（<ミーティング名・日付>）
   ### 済み（人不要）
   - <やったこと> → <下書き・成果物の場所>
   ### 承認待ち（人必要）
   - <やること>｜準備済みのもの｜承認したら何が起きるか
   ### 要確認
   - <確認したいこと>
   ### 相手のタスク（記録のみ）
   - (<相手の名前>) <やること>
   ```

## やってはいけないこと

- 承認なしでメッセージやメールを送る、投稿する、予定を確定する
- 文字起こしにないタスクを作る（推測で増やさない）
- 相手のタスクを自分のタスクとして実行する

## 調整のしどころ（自分向けにチューニングする）

発動条件は人によって違うので、使いながら次を決めていく。
- どの言い回しをネクストアクションとみなすか（「検討します」は入れるか など）
- 人不要と人必要の境目（例：社内 Slack への投稿は人不要にする、など）
- 下書きの置き場所と、承認の受け方（LINE、Slack、Grok ボットなど）
- 録音が終わったら自動で動かすか、「リキャップ作って」と言われたら動かすか
