## 2. AIコンテンツ：何を人がやり、何をAIがやるか

| 人がやる（肝） | AIに任せる |
|---|---|
| アカウントに人が来る理由・投稿の面白さ | 情報収集・データ収集 |
| 企画・切り口（例：医師のコメント・独自の視点） | 構成の下書き・媒体ごとの書き分け |
| 何が足りないかの判断 | 被リンク付けなど周辺作業 |

**例：オンラインクリニック** — 病気や薬の網羅記事を100本書くのは簡単だが、ほぼ読まれない。
「この記事に来ると独自の情報がある」と、読者にもアルゴリズムにも伝わる部分を人が作る。

まず人力でやってみて、AIにできそうな部分から順にAIへ移す。

---

## 3. エージェントは1体から育てる

```
記事を書くエージェント（1体）
  → 出力を読み、何が足りないかを人が言語化
  → 批評エージェントを追加（医療の視点 / 最新SEOを知るマーケター）
  → 批評 → 修正 のループ
  → 記事をインスタ用画像にするエージェントへ展開
  → 増えたエージェントを「いつ・どれを呼ぶか」決める ＝ Agent Teams
```

**体制図・オペレーションから設計しない。**
基盤となる1本のコンテンツの作り方が分からないと、複製も自動化もできない。

---

## 4. 目的とコンテンツの流れ

- **目的**：自社LINEへのリストイン（オーガニック集客）
- **やり方**：AIアフィリエイターのように、いろいろなカテゴリのアカウントを作る
- **第一接点**：インスタ・TikTokのショート動画やフィード
- **展開**：note記事を半自動化 → Threads・X向けにも書き分け

**狙う形：** 企画（インプット）を入れると、各媒体に最適化された
アウトプットが出る仕組み。そのほうが品質を担保しやすい。
