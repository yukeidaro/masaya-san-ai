# 2026/10/23 ミーティング要約

## ツールが増えたら「役割」を決め、タスクは「どこで進むか」で分ける

学習に関係する要点を抜粋

---

## 今回のポイント

1. **悩みが「画面の数」から「ツールの数」へ**：どれを使うか決めるコストが負担に
2. **Grokボットは開発に深くつながない**：予約・思いつきメモ・声での操作に使う
3. **AIに書かせるタスクは専用カレンダーへ**：他の人の予定の枠を潰さない
4. **欲しいのは「秘書」**：止まっているセッションと確認待ちを把握し、次の一手を出してほしい

> できることは Claude Code や Codex と同じで、形式（声・スマホ）が違うだけ。

---

## 1. ツールの乱立と「使い分けのコスト」

- 今使っているもの：**Grokボット / Codex / Dots / Claude Code / Gemini**（Gemini は検索代わりの私用）
- 新しいアシスタント（例：Muse）も Gmail につなぐと、**全員が同じ返信案を出してくる** 重複が起きる
- 今月いちばん大きかった変化：外出先から **スマホ1台で Claude Code と Codex をリモート操作**（離れた場所のPCを手元から動かすこと）できるようになった

**対策の考え方：** ツールごとに「何をさせるか」を先に決める。
同じ仕事を複数のアシスタントにさせない。

---

## 2. Grokボットの使いどころ

| 向いている | 向いていない |
|---|---|
| 食事・イベントの予約（一度ログインさせておけば Web 予約まで） | 開発作業への深い接続 |
| 思いついたことのメモ → Codex / Claude Code に渡す | Claude Code の直接操作（画面操作経由になる） |
| 声でのやりとり、場所をきっかけにした通知 | 細かい進捗管理の主役 |

- クラウドで動くので、**PCとスマホで同じ画面が常に同期** される（リモート操作のオン・オフ不要）
- ボットごとに長めのプロンプトで役割を決め、**ルーティン（決まった時刻の自動実行）** をつなぐ

---

## 3. 参考：朝の運用例（Yu の場合）

```
朝、Grokボットと声で会話
  → 事前に用意させたニュース・メール返信案・Slackの要対応を確認
  → 今日の優先事項を声で決める
  → Googleカレンダーに作業の枠を入れさせる（30分〜1時間半など）
  → Claude Code に頼むタスクはスプレッドシートに入れさせる
  → Claude Code がルーティンでシートを読み、セッションに投げる
```

- 長期の計画は Claude の **Artifact（共有できるWebページ）** にまとめ、日次のToDoまで落として毎週更新
- タスク表は正直あまり見ない。**毎日見るもの（カレンダー）に載せる** のがコツ

---

## 4. Masayaさんの理想：「秘書」がほしい

**今の状態**
- タスクは Notion に手動で入力。ステータスの更新が続かず、スマホの UI もストレス
- Googleカレンダーは関係者が自由に予定を入れる箱なので、タスクを入れにくい
- 自分専用のタスク管理アプリを作っている途中

**ほしい体験**
- どのセッションが動いていて、どれが **自分の確認待ちで止まっている** かを把握してくれる
- 外出時などに「このセッション、あと一押しで完了しそう。進めますか？」と提案してくれる
- 優先度は高いが緊急でないタスクも、忘れないよう声をかけてくれる

---

## 5. 理想に近づくための打ち手

1. **タスクを「どこで進むか」で分類する**
   事業ごとに使うAI・PCが違う（例：Codex で処理する事業、会社PCの Claude Code で進める事業）。
   一次情報（Slack・メール・カレンダー・どのセッション）が決まれば、AIが進捗を追える
2. **タスク用のGoogleカレンダーを別に作る**
   「＋」→ 新しいカレンダーを作成し、AIに書き込ませる。他の人の予約の邪魔をしない
3. **定時のリマインド**：昼・15時などに「忘れていませんか」と声をかけさせる
4. **所要時間の目安を学習させる**：過去の実績を少し入れて、AIに見積もりを提案させる
5. **Muse を試す**：会話がそのまま「ゴール（ToDo）」として記録される。無料。ただし Claude Code・Codex との連携は未確認

---

## 次に試すこと

- Notion のタスクに「どこで進むか（ツール・PC・一次情報）」を1列足す
- タスク専用のGoogleカレンダーを作り、AIに作業枠を書かせてみる
- Grokボットの役割を3つに絞る：予約 / 思いつきメモ / 外出時の確認
- 週末に「秘書にしてほしいこと」を声で話して書き出し、タスク管理アプリの要件にする

**現在地は Tier 8。** 複数のAI・セッションを動かす段階から、
それらを「誰が・どこで・いつ」見張るかを決める段階へ。
