## 1. Agent Teams とは

AI が**組織図を自動生成**し、各エージェントに役割・人格・シナリオを付与してタスクを回す Claude Code の機能。

  subgraph TEAM["Agent Teams"]

**違いは「エージェント同士が会話するか」**。

---

## 1. Agent Teams の利点とコスト

| 観点 | 通常のオートモード | Agent Teams |
|------|------------------|-------------|
| 承認回数 | 多い（都度止まる） | **大幅に減る** |
| 稼働時間 | 承認待ちで断続的 | **長時間、継続的に作業** |
| アウトプット | ばらつく | **安定しやすい**（会話設計に依存） |
| トークン消費 | 標準 | **非常に大きい** |

- 有効なのは**複数タスクが絡む**とき: クリエイティブ検知 → Meta 広告分析 → Figma 制作 → PDCA 実行。
- 導入は Claude Code Docs の「ページをコピー」→ Claude に貼って依頼するだけ。

## 2. Skills が発動しない理由

Masaya の Skills は 4 つ。うち **Inbox Routing が一度も発動していない**。

<div class="mermaid">
graph LR
  T["トリガー（発動の合図）"] --> D["やること（手順）"]
  D --> O[アウトプット]
  style T fill:#ffd7d7,stroke:#c00
</div>

- Skills の構造は「**発動の合図 ＋ やること**」。**手順だけ書いても発動しない**。
- Masaya の Skills には**トリガーが定義されていなかった**。
- 「回答のピントが合ってきた」実感は Skills ではなく**メモリー**の作用。
- Session Review は発動しているが、**ラーニングが溜まっているだけ**で改善が実行されていない。

---

## 2. まずやること：トリガーを付ける

- 「毎週 1 回」「◯◯と言われたとき」など、**何でもよいのでトリガーを定義**する。
- 作業は Claude に任せてよい: **「この Skills にトリガーを追加して、自動実行できるようにして」**。
- 狙いは、**自分が呼ばなくてもエージェントが勝手に参照する**状態。
- Skills は増えると人間が数えられなくなる → **自動参照できないと死蔵する**。

---

## 3. 公式スキルライブラリを入れる

- Anthropic が GitHub で公開している**公式スキル一覧**を導入する。
- 導入方法: **リンク自体を Claude Code に貼るだけ**で一括インポート。
- 含まれるもの:
  - **Skill Creator（スキルを作るスキル）**
  - PowerPoint 操作 / PDF 操作
  - Slack 系ツールほか
- 導入後は `/skill creator` で**新しい Skills を作れる**ようになる。

---

## 3. セキュリティ注意

> X などで公開されているサードパーティ Skills には、**データを抜き取るもの**が存在する。

- 「便利そうだから」で入れない。
- **Anthropic 公式のものだけ**を使う。
- スキルは実行権限を持つ手順書。**出所の確認は必須**。

## 4. 足りないのは「評価ループ」

知識を**生成 → 評価 → 改善**まで自動で回す部分が回っていない。

<div class="mermaid">
graph LR
  G[生成] --> E[評価]
  E --> I[改善]
  I --> G
  style E fill:#ffd7d7,stroke:#c00
  style I fill:#ffd7d7,stroke:#c00
</div>

**具体アクション 5 つ**

1. **情報に日付を付ける** — AI が鮮度を判断できるように
2. **一時メモリと長期メモリを分ける** — 今は混在している
3. **Skills にトリガーを付ける** — 自動参照させる
4. **Agent Teams / サブエージェント**で小タスクを自律実行
5. **Session Review の提案を実行に移す**

---

## 4. Session Review は「実行」までがセット

- セッション終了時に、自動化候補と改善点が **3 つほど提示**される。
- そこで「なるほど」で終わると、**何も変わらない**。
- 「OK、それを実行しましょう」まで進めて初めて**オートメーション化される**。
- これを積み重ねることで、環境は継続的に良くなっていく。

---

## 5. 広告レポート自動化（Masaya の直近テーマ）

**やりたいこと**: 広告媒体と連携し、レポートを**自動で継続的に回し続ける**。

- **粒度**: キャンペーン / 広告セット / 媒体 / **クリエイティブ（最小単位）**
- **必須要件**: 「**いつ・何を・どういう背景で**」実施したかのメモを全て残す
- **痛み**: 予算は**減額より増額が危険**。ルールを外すと暴発する
- 前任者の手書きメモを AI で掘って過去傾向を出し、**今回は被害を回避できた**
- 課題は「**アカデミックな知見ではなく、経験則から生まれる避けるべきこと**」の洗い出し

---

## 5. 実装方針

<div class="mermaid">
graph LR
  D["経験則をドキュメント化"] --> U[アップロード]
  U --> N["禁止事項として設定"]
  N --> C["エージェントが状況確認"]
  C --> A["アクションを吟味・実行"]
  A --> L["いつ・何を・なぜ を記録"]
  L --> C
</div>

- 制約: **データ化されていないと難しい**。まず暗黙知を書き出すところから。
- 要件は**音声でそのまま投げてよい**（端的にまとめられなくても問題ない）。
- 希望時期: **今週末**。

# まとめ

**Skills は「書く」より「発動させる」**。トリガーが無いスキルは存在しないのと同じ。

公式ライブラリで土台を入れ、トリガーを付け、**Session Review の提案を実行に移す**。
その先に、経験則を禁止事項に変えた**広告レポートの自律運用**がある。
